# Machine Learning Projects

A collection of machine learning projects built while learning and applying fundamental machine learning concepts using Python.

## Projects

### 1. Diabetes Prediction

A binary classification model that predicts whether a person is likely to have diabetes based on health-related features.

* **Dataset:** 768 samples, 8 features
* **Accuracy:** 77.27%

**Concepts:** Classification, data preprocessing, model training, model evaluation

---

### 2. House Price Prediction

A regression model that predicts house prices based on property-related features.

* **Dataset:** 20,640 samples, 8 features
* **R² Score:** 0.837
* **Mean Absolute Error (MAE):** 0.308

**Concepts:** Regression, data preprocessing, model training, model evaluation

---

### 3. Rock vs Mine Classification

A binary classification model that uses sonar data to determine whether an object is a **rock or a mine**.

* **Accuracy:** 76.19%

**Concepts:** Binary classification, data preprocessing, model training, model evaluation
